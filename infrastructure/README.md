# Infrastructure & Deployment

This directory contains deployment specifications, container blueprints, and maintenance scripts.

- **`render/`**: Blueprint specifications (`render.yaml`) for hosting `apps/api` (Python Web Service) and `apps/web` (Node Web Service) on Render.
- **`docker/`**: Future containerization files for local orchestration or alternative container environments.
- **`scripts/`**: Operational scripts (e.g., database migration runners, backup scripts, seed data utilities).
